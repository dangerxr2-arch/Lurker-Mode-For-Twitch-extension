# Changelog

## 0.1.0

- First public version.
- Icon in the Twitch chat header (red = off, gray = on).
- Read-only chat through an anonymous connection, shown inside the chat column.
- Usernames, user colors and Twitch emotes.
- Deleted messages and timeouts shown struck through.
- Smart auto-scroll with a "jump to end" button.
- Automatic reconnection.
- Remembers the channels where it was enabled.
